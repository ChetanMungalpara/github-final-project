# Simple Interest Calculator

A shell script that calculates simple interest given principal, annual rate of interest, and time period in years.

## Description
This project is part of the IBM Git & GitHub course. It contains a simple script that demonstrates basic mathematical operations and user input handling in a terminal environment.

## Formula
The calculation is based on the standard simple interest formula:
$I = \frac{P \times R \times T}{100}$

Where:
* *P* = Principal amount
* *R* = Annual interest rate
* *T* = Time period in years
